 東京ステーションガイド アップローダー
 GitHub へ «まとめて» と «変わったぶんだけ» を上げるための道具
================================================================

■ できること
  ・フォルダの中身を、GitHub へ1回のコミットでまとめて反映
  ・2回目からは «変わったファイルだけ» を送る（差分反映）
  ・いらなくなったファイルを GitHub 側から消す
  ・升目データ（4,000枚以上）のような大量のファイルも扱える

  ブラウザのドラッグ＆ドロップと違い、数千ファイルでも途中で
  失敗しません。


■ 使うまでの手順（はじめの1回だけ、10分ほど）

 【1】Python を入れる（もう入っている方は飛ばしてください）

    https://www.python.org/downloads/windows/
    「Download Python 3.x.x」を押して、インストーラを実行。

    ★ 最初の画面で「Add python.exe to PATH」に必ずチェック ★

    確認： スタートメニューで「cmd」と打ってコマンドプロンプトを開き
           python --version
           と入れて、バージョンが出ればOKです。

 【2】GitHub のアクセストークンを作る

    1) GitHub にログイン → 右上のアイコン → Settings
    2) 左のいちばん下 → Developer settings
    3) Personal access tokens → Tokens (classic)
       → Generate new token (classic)
    4) Note に「tsg uploader」など、好きな名前
    5) Expiration（期限）は 90 days などお好みで
    6) Select scopes は «repo» にチェック（これだけでOK）
    7) いちばん下の Generate token
    8) ghp_ で始まる文字列が出るので、コピーしておく

    ※ この画面を離れると二度と見られません。コピーを忘れずに。
    ※ トークンはパスワードと同じです。人に見せないでください。

 【3】起動する

    「起動.bat」をダブルクリック。
    （うまくいかないときは、tsg_uploader.py を右クリック →
      プログラムから開く → Python）


■ 毎回の使いかた

  1) 画面の «上げるフォルダ» で、tokyostation フォルダをえらぶ
  2) «下見だけ» にチェックを入れたまま
     «① 変わったものだけ上げる» を押す
     → 何が増える・変わる・消えるかが表に出ます
  3) 内容を見て問題なければ «下見だけ» のチェックを外し、
     もう一度 «① 変わったものだけ上げる» を押す
  4) 2〜3分待つと、公開ページに反映されます


■ 2つのボタンの違い

  ① 変わったものだけ上げる（ふだんはこちら）
     手元にあるファイルのうち、変わったものだけを送ります。
     GitHub 側にしかないファイルは、そのまま残ります。

  ② ぜんぶ入れ替える
     手元のフォルダと «まったく同じ» 状態にします。
     手元に無いファイルは GitHub からも消えます。
     いらないファイルを一掃したいときに使ってください。


■ 上げないファイル（自動で除きます）

  *.pyc / __pycache__ / .git / node_modules / *.zip
  standalone.html（単一ファイル版。GitHub には要りません）
  .DS_Store / Thumbs.db / *.tmp / *.log


■ 困ったとき

  「GitHub が 401 を返しました」
    → トークンが違うか、期限切れです。作り直してください。

  「GitHub が 404 を返しました」
    → ユーザー名かリポジトリ名の打ち間違いです。

  「GitHub が 403 を返しました」
    → 少し待ってからやり直してください（回数の制限です）。
       トークンの scope に «repo» が入っているかもご確認を。

  入れた内容の保存先
    C:\Users\（あなた）\.tsg_uploader.json
    ここにトークンも入ります。パソコンを人に貸すときはご注意を。
