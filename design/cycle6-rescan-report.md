## 4. コントラスト実測（回答シート材料 — 色の決定はユーザー判断）

DOM の computed style から実効 fg/bg を合成して WCAG 比を実測。ヒーロー主ボタンは後段 CSS の上書きで単色ではなくオレンジグラデーション（rgb(255,138,60)→rgb(255,90,54)）が実効背景であり、両端で手計算した。

推奨案（いずれも未実施）:
