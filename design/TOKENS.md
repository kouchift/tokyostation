# 見た目のトークン（v171）

見た目の «元の値» は `assets/app.css` の先頭の `:root` に集めてある。新しい決まりを書くときは、生の数値や色ではなく、ここにある変数を使う。
（`tools/css_tokens.mjs` が、生の値を段階に写す。直したあとは `node tools/css_tokens.mjs` で下見 → `--write`）

## 色

| 変数 | 値 | 使いどころ |
|---|---|---|
| `--ink` | #181c20 | 本文・見出し（白地で 15:1） |
| `--ink-2` | #404751 | 補助の文字・ラベル（9.4:1） |
| `--ink-3` | #5F6772 | いちばん薄い文字（5.7:1。これより薄くしない） |
| `--line` / `--line-2` | #D9DFE8 / #C0C7D3 | 枠線・区切り / 強めの枠線 |
| `--paper` / `--paper-2` / `--paper-3` | #fff / #F7F9FF / #EBEEF4 | 面 / 薄い面（帯・一覧）/ 押せる面（チップ・副ボタン） |
| `--brand` / `--brand-ink` / `--brand-2` | #0055AD / #00224A / #008BF2 | 主ボタン・リンク / ヘッダーの印 / 強調・フォーカス |
| `--brand-50` / `--brand-200` | #F0F9FF / #C0E4FF | 選択中の面 / 選択中の枠 |
| `--good` / `--warn` / `--bad` | #197A4B / #8F4C00 / #C62828 | できた / 注意 / 危険 |

暗いカード（`.modal--dark` `.card--dark`）の中では `--ink*` `--line*` `--paper*` が反転する（同じ変数名で書けば両方で読める）。

古い名前（`--text` `--label` `--muted` `--lb900` `--tsg-*` など）はまだ残っているが、新しく書くときは上の名前を使う。

## 角丸

`--r-xs` 4 / `--r-sm` 8 / `--r-md` 12 / `--r-lg` 16 / `--r-xl` 24 / `--r-pill` 999。丸いもの（アイコンの丸・現在地の印）は `50%`。

## 文字の大きさ

`--fs-11` … `--fs-28`（11 / 12 / 13 / 14 / 16 / 18 / 20 / 22 / 24 / 26 / 28）。

- 本文は 14〜16、補助は 12〜13、最小は 11（これより小さくしない）
- 行間は本文 1.6〜1.7、見出し 1.25〜1.35
- 画面の文字の欧文・数字は Plus Jakarta Sans / JetBrains Mono（`--mono`）。日本語は端末の書体

## 影

`--sh-1`（ふち・チップ）/ `--sh-2`（浮くカード・ふきだし）/ `--sh-3`（窓・シート）。

## 動き

`--t-fast` 120ms（色・押下）/ `--t-base` 180ms（出入り・トースト）/ `--t-slow` 240ms（大きな窓）。イージングは `--ease`（cubic-bezier(.2,.8,.2,1)）。
`prefers-reduced-motion: reduce` では全部 0ms。0.5 秒より長い動きは «演出»（読み込みの帯・光る印）だけ。

## 例外（トークンを使わないもの）

- 地図の中の文字（駅名・区名・ランドマーク）… `calc(... * var(--u))` で «画面 px» に合わせて JS が決める
- 路線の色・ジャンルの色 … データ（`data/lines_meta.js` `data/genres.js`）が持つ色。札の文字色は `RG.lineFg` が黒／白を選ぶ
- ブランドの紺（#00224A）と絵文字のロゴ 🚉 … 変えない
- SNS の色（LINE・Instagram・X …）… 各社の色。文字色だけ読める濃さに
- 夜（終電後）の `body.night`、暗いカード、通信を節約する `qos-lite` … 変数の値を切り替えるだけ（決まりを増やさない）
- z-index は 41 段あるまま（R3 以降で整理）
